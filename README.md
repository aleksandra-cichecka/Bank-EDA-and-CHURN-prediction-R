# Bank-EDA-and-CHURN-prediction
This project focuses on analyzing bank customer data through Exploratory Data Analysis (EDA) and using a predictive model to identify customers likely to churn. The goal is to help the bank lower its churn rate.

#Overview

This project presents an analysis of bank customer churn data, obtained from the Customer-Churn-Record dataset available on Kaggle. It's divided into three main parts

1. Data Preparation and Cleaning
2. Descriptive Analysis
3. Churn Prediction using Random Forest

A deployed version of this can be found [here](https://aleksandra-cichecka.github.io/Bank-EDA-and-CHURN-prediction/)
