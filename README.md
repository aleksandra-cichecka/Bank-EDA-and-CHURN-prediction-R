# Bank-EDA-and-CHURN-prediction
This project focuses on analyzing bank customer data through Exploratory Data Analysis (EDA) and using a predictive model to identify customers likely to churn. The goal is to help the bank lower its churn rate.

# Overview

This project presents an analysis of bank customer churn data, obtained from the Customer-Churn-Record dataset available on Kaggle. It's divided into three main stages:

1. **Data Preparation and Cleaning** - checked for missing values, correct data types, removed non-informative columns
2. **Descriptive Analysis** - explored churn patterns across different columns, visualized every variable
3. **Churn Prediction** - used Random Forest classifier to develop a churn prediction model, identified high-risk customers, pinpointed the variables most responsible for elevated churn

A deployed version of this can be found [here](https://aleksandra-cichecka.github.io/Bank-EDA-and-CHURN-prediction/)
